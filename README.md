# ESP32-Based Smart Home Automation System

## Project Overview

This project is an IoT-based home automation system developed using ESP32. It allows users to control home appliances and devices remotely through a smartphone using Wi-Fi connectivity.

The system uses an ESP32 microcontroller to receive commands from a smartphone and control different output devices.

## Components Required

- ESP32 Development Board
- LED
- Servo Motor
- Relay Module
- Smartphone
- Jumper Wires
- Breadboard
- Power Supply

## Working Principle

1. ESP32 connects to a Wi-Fi network.
2. The smartphone communicates with ESP32 through a Wi-Fi-based control interface.
3. The LED can be switched ON and OFF remotely.
4. The servo motor can be controlled to adjust its position.
5. The relay module is used to control electrical appliances.
6. Commands from the smartphone are processed by ESP32 to control the connected devices.
